Typing Fighter

How to play

Start a duel

Type start and press Enter. Both fighters start at 5 HP.

Type a spell name and press Enter to cast it. The computer replies if it has HP left. Each fighter can use each spell once per duel.

Winning Conditions

The first fighter to reach 0 HP loses. If both run out of spells, the fighter with more HP wins. Equal HP is a draw. Click Restart to play again.
